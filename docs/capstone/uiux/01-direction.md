# UI/UX Direction

## Aesthetic Mode
**Arcade High-Speed Experience**:
- Vaporwave / Synthwave aesthetic inspired by arcade classics (OutRun, Ridge Racer) adapted to modern endless runner mechanics (Subway Surfers).
- Primary visual drivers: Vibrant magenta city skyline, deep navy night sky with twinkling stars, high-contrast neon cyan road lanes with flashing white/red kerb strips.
- Feedback-first arcade typography: High visibility Mode 0 text with dedicated color escape sequences for game events (`[HURDLE!]`, `[DRIFT!]`, `[CLOSE!]`, `[NITRO!]`).
